# 📖 Comandes bàsiques – `programafinal.py`

| Comanda | Què fa |
|---------|--------|
| `python3 programafinal.py` | Mostra totes les estacions de Bicing i AMBici. |
| `python3 programafinal.py --top 5` | Mostra només les 5 millors estacions segons canvi ràpid. |
| `python3 programafinal.py --barri Sants` | Mostra només les estacions que contenen “Sants” al nom. |
| `python3 programafinal.py --coords 41.3751 2.1497 --radi 500` | Mostra les estacions dins un radi de 500 m al voltant de Plaça Espanya. |
| `python3 programafinal.py --transbord` | Mostra els punts de transbord entre Bicing i AMBici (estacions a <250 m). |
| `python3 programafinal.py --transbord --coords 41.4036 2.1910 --radi 300` | Mostra només els punts de transbord dins 300 m de Glòries. |
| `python3 programafinal.py --output estacions.csv` | Desa totes les estacions en un fitxer CSV. |
